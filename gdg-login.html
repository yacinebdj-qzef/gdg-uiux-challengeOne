GDG Login – Challenge N:01

UX study → wireframe → final UI, with light/dark theme and a mobile version.

1 · UX study

Main path (happy path)

Open screen→See welcome + GDG brand→Enter email→Enter password→Tap Sign in→Logged in
Alt path

Forgot password

Link under the password field → enter email → “reset link sent” → back to sign in.

Alt path

New account

“Create account” link → name, email, password → join the chapter → logged in.

Alt path

Google sign-in

One-tap “Continue with Google” skips the form for members who prefer it.

Error path

Wrong details

Inline message under the field, input keeps its value, focus returns to the problem field.
